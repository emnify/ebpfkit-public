# tech.emnify.com/go/ebpfkit

eBPF-related technologies

## [promexporter](promexporter)

Package `promexporter` exposes metrics hosted in eBPF per-CPU array map to Prometheus.

## [testing/ebpftest](testing/ebpftest)

`ebpftest` package contains Golang utilities and helpers that simplify testing of eBPF programs from Golang userpace.

For the first time ever, mocking meets eBPF!
